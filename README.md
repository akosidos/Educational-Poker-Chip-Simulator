# Poker Chip Simulator

## About the Project

Poker Chip Simulator is a web-based project created for **educational purposes**. The application demonstrates how HTML, CSS, and JavaScript can be used together to create an interactive system that performs calculations, manages user actions, updates data dynamically, and stores information locally in the browser.

The simulator is designed to manage **virtual poker chips** during a game. It can keep track of player chip balances, bets, raises, calls, folds, all-ins, the current pot, and the winner of each hand.

## Educational Purpose

This project was created as a programming exercise and **does not promote, facilitate, or encourage real-money gambling**.

The poker theme is used only as a practical scenario for demonstrating programming concepts such as:

- JavaScript functions and calculations
- Variables, arrays, and objects
- Conditional statements
- Event listeners
- DOM manipulation
- Input validation
- Local storage
- HTML interface design
- CSS transitions and interactive UI states

## No Real-Money Gambling

## Features

The Poker Chip Simulator currently includes:

- Support for multiple players
- Custom player names
- Custom starting chip balances
- Automatic Initial Pot Bet
- Check
- Bet
- Call
- Raise
- Fold
- All-In
- Automatic pot calculation
- Automatic chip deduction
- Player status tracking
- Manual winner selection
- Automatic pot awarding
- Multiple-hand support
- Game activity log
- Browser Local Storage
- Responsive interface
- CSS transitions and interactive button states

## Technologies Used

- **HTML5** — Website structure and interface
- **CSS3** — Styling, responsive design, transitions, and animations
- **JavaScript** — Game calculations, chip management, validation, and application logic
- **Local Storage** — Saves the current simulator state in the user's browser

## Usage

Open `index.html` in a modern web browser or deploy the project using a static web hosting service such as GitHub Pages.

No database, PHP server, or backend is required because all calculations are performed using JavaScript in the browser.
